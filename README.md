# DevOps-Git-Project
DevOps-Git-Project

Git is Local repo which works on the Developers Machine.

The first list of Commands:

Git init: Initializes the Normal Directory to a Git Repo
Git Add: Moves the Files from Working Directory to Staging
Git Commit -m ""  : Moves the files from Staging to Local Repo
